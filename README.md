# Wanderlust

Wanderlust is a full-stack web application where users can explore and create property listings.

Users can sign up, log in, create listings, upload images, edit or delete their listings, and leave reviews.

## Live Website

https://wanderlust-8r2m.onrender.com

## Technologies Used

HTML, CSS, JavaScript, Node.js, Express.js, EJS, MongoDB, Cloudinary and Mapbox.

## Note

This project is still under development. Some features and category filters are not fully functional yet.
